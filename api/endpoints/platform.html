Platform

Identity, organization lifecycle, membership, invitations, and the dashboard bundle. Routes that the app shell hits before any tenant-scoped data loads.

Endpoints E001–E019. Each maps 1:1 to the L3 workflow with the same number — see the master endpoints table for the flat view.

Writes​

  • E001 POST /me/sign-up — Sign up → W001
  • E002 POST /auth/log-out — Log out → W002
  • E003 POST /organizations — Create organization → W003
  • E004 PATCH /organizations/current — Update organization → W004
  • E005 DELETE /organizations/current — Delete organization → W005
  • E006 PATCH /organization-users/:userId — Update user role → W006
  • E007 DELETE /organization-users/:userId — Remove user from organization → W007
  • E008 POST /invitations — Send invitation → W008
  • E009 POST /invitations/:id/resend — Resend invitation → W009
  • E010 DELETE /invitations/:id — Revoke invitation → W010
  • E011 POST /invitations/accept — Accept invitation → W011
  • E012 POST /invitations/decline — Decline invitation → W012

Reads​

  • E013 GET /me — Get current user → W013
  • E014 GET /organizations/current — Get organization → W014
  • E015 GET /organization-users — List organization users → W015
  • E016 GET /me/invitations — List my pending invitations → W016
  • E017 GET /invitations — List organization invitations → W017
  • E018 GET /invitations/by-token/:token — Look up invitation by token → W018
  • E019 GET /dashboard — Get dashboard → W019
