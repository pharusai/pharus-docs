Materials

Workflows for raw-material master data and material types. Mirrors Products in shape; the same delete-gating rules apply because materials carry the same downstream-reference exposure.

Composes: Materials, PurchaseOrders, WorkOrders, BOM, MaterialsInventory.

Writes​

1. Create material​

Triggered from the Materials page → "New material".

Composes: Materials.

Steps:

  1. Verify code is unique within this org (case-insensitive).
  2. If typeId is set, verify it exists.
  3. Materials.createMaterial.

Errors: ValidationError, NotFoundError.

2. Update material​

Triggered from Material Detail.

Composes: Materials.

Steps:

  1. Materials.getMaterialById.
  2. If patch changes code, verify uniqueness.
  3. If patch changes typeId, verify the type exists.
  4. Materials.updateMaterial.

Errors: NotFoundError, ValidationError.

3. Delete material​

Triggered from Material Detail.

Composes: Materials, PurchaseOrders, BOM, MaterialsInventory.

Steps:

  1. Materials.getMaterialById.
  2. In-use checks across PO items, BOM input rows, and the materials ledger.
  3. Refuse if any reference exists.
  4. Materials.deleteMaterial.

Business rules:

  • Soft-delete (archive) via §4 is the routine path.

Errors: NotFoundError, InUseError.

4. Reactivate material​

Composes: Materials.

Steps: Materials.setMaterialActive(materialId, true).

Errors: NotFoundError.

5. Bulk-import materials​

Composes: Materials.

Steps: parse, abort on parse errors, then run §1 for each row inside one transaction.

Errors: ValidationError.

6. Create material type​

Composes: Materials.

Steps: verify name uniqueness, Materials.createMaterialType.

Errors: ValidationError.

7. Update material type​

Composes: Materials.

Steps: load, check name uniqueness if changed, updateMaterialType.

Errors: NotFoundError, ValidationError.

8. Delete material type​

Composes: Materials.

Steps:

  1. Materials.isMaterialTypeInUse.
  2. Materials.deleteMaterialType if not in use.

Errors: InUseError.

Reads​

9. List materials​

Composes: Materials.

Steps: Materials.listMaterials(filters).

10. Get material detail​

Triggered by clicking a material.

Composes: Materials, PurchaseOrders, BOM, MaterialsInventory.

Steps:

  1. Materials.getMaterialById.
  2. Surface usage info — counts of PO references, BOMs that include this material, and the latest weighted-average unit cost from MaterialsInventory.listEntries. These are derived counts; the L4 layer chooses which to render.

11. List material types​

Composes: Materials.

Steps: Materials.listMaterialTypes.

12. Check if material type is in use​

Composes: Materials.

Steps: Materials.isMaterialTypeInUse.
